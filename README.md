# تطبيق الرواتب والدوام

تطبيق ويب يعمل بدون إنترنت لإدارة الموظفين والرواتب الشهرية والسلف والساعات الإضافية وحاسبة الدوام والملخص السنوي.

البيانات تُحفظ على جهاز المستخدم فقط (لا تُرفع إلى أي خادم).

## Tests

See [`tests/README.md`](tests/README.md). Quick start: `cd tests && npm install && npm test`.
